# Security policy

Gatekeeper is a specification draft with no implementation yet. Weaknesses
in the design (for example a reconstruction attack the specification does
not prevent) are still security issues and are welcome.

## Reporting

Please report privately through GitHub's
[security advisories](https://github.com/ruslanzykun/gatekeeper/security/advisories/new)
("Report a vulnerability"). Do not open a public issue for a suspected
vulnerability.

Include what you found, how it can be exploited, and, if possible, a
sequence of questions or inputs that demonstrates it. You will receive an
acknowledgement, and fixed design issues will be credited in the
specification unless you prefer otherwise.
